# 隧道收敛测缝台

测量员登记里程桩号与收敛毫米值。接口进程内后台线程认领待判行（不另起 worker 容器），按当前琥珀带三档判定：合格 / 近阈 / 超限。页面是 Svelte。

## 判定规则（琥珀近阈带）

- 合格带：|收敛| ≤ 内缘（默认 ±3.0 mm）→ **合格**
- 琥珀近阈区：内缘 < |收敛| ≤ 外缘（默认 3.0~3.4 mm）→ **近阈**，仍可进队，只是标近阈
- 超出外缘（默认 ±3.4 mm）才算 **超限**

页眉可进「琥珀专页」：看当前内缘、外缘、三档样例色和改带履历；测量员可在此改带，巡检员只读不能改带。改带只作用于之后新交的单；已领走的单据仍按领走时快照的琥珀界判定与展示，不追溯。总表着色与详情注脚共用同一套判定界（单据上的快照），保证一致。

例：琥珀带 3.0~3.4 时，报 3.2 → 近阈（不是超限），报 3.8 → 超限。

## 技术栈

- 后端：Flask、Gunicorn、SQLAlchemy、进程内认领线程
- 前端：Svelte、Vite、nginx 反代 `/api`
- 数据库：PostgreSQL 16

## 接口

| 方法 | 路径 | 说明 |
|------|------|------|
| POST | `/api/auth/login` | 登录 |
| GET | `/api/logs` | 单据总表（含领走时快照的判定界） |
| POST | `/api/logs` | 提交读数（仅测量员；琥珀区值也可进队） |
| GET | `/api/logs/<id>` | 单据详情 |
| GET | `/api/band` | 当前琥珀带（内缘/外缘） |
| GET | `/api/band/history` | 改带履历 |
| POST | `/api/band` | 改带（仅测量员；外缘须大于内缘） |
